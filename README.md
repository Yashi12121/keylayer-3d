# Keylayer 3D

Interactive 3D mechanical keyboard built with React, Three.js, and Vite.

Live site: https://yashi12121.github.io/keylayer-3d/

## Development

```sh
npm ci
npm run dev
```

## Publish

```sh
npm run deploy
```

The deploy command builds the site and publishes `dist` to the `gh-pages` branch.
GitHub Pages serves that branch from its root. Git access to this repository is
required to publish updates. Commit and push source changes to `main` separately.
